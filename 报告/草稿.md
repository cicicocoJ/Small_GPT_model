五、修改 `tiny_tokenizer.py` 中的 `SimpleRegexTokenizer`

请修改 `SimpleRegexTokenizer`，使其把 `<|endoftext|>` 当作完整特殊 token 处理。

具体要求：

1. `encode()` 时正则表达式必须优先匹配完整的 `<|endoftext|>`，不要把它拆成：

   * `<`
   * `|`
   * `endoftext`
   * `|`
   * `>`

2. `build_from_text()` 时词表中必须包含完整 token：

```text
<|endoftext|>
```

3. `eos_id` 必须返回 `<|endoftext|>` 对应的 token id。

4. `pad_id` 可以复用 `eos_id`。

5. `decode()` 时，如果遇到 `<|endoftext|>`：

   * 可以保持为 `<|endoftext|>`；
   * 或者通过参数控制是否跳过；
   * 但绝对不要显示成 `< | endoftext | >`。

6. 建议给 `decode()` 增加参数：

```python
def decode(self, token_ids: list[int], skip_special_tokens: bool = False) -> str:
```

当 `skip_special_tokens=True` 时，不输出 `<|endoftext|>`。

7. 保存 `pretrain_sample.txt` 时，使用：

```python
tokenizer.decode(generated_ids, skip_special_tokens=True)
```

如果 `GPT2Tokenizer.decode()` 没有这个参数，也请兼容处理，可以给 `GPT2Tokenizer.decode()` 也增加同名参数。

8. 在 `generate_text()` 中，如果生成的 `next_token_id == tokenizer.eos_id`，就提前停止生成。

9. 生成样例保存时，默认去掉末尾的 `<|endoftext|>`，不要在 `pretrain_sample.txt` 中显示 `< | endoftext | >`。
