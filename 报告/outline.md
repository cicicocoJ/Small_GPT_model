# 2 大语言模型相关理论基础

## 2.1 大语言模型与 GPT 架构

大语言模型是一类基于深度神经网络的自然语言处理模型，通常使用大规模文本数据进行训练。其核心思想是通过学习文本序列中的统计规律，预测下一个词或 token，从而获得文本生成、语义理解和任务迁移能力。

GPT 模型采用 Decoder-only Transformer 结构，只使用 Transformer 解码器部分，并通过因果遮罩保证模型在预测当前位置时只能看到当前位置之前的信息。

### 2.1.1 大语言模型基本概念

介绍大语言模型的定义、特点和基本工作方式。

### 2.1.2 GPT 的 Decoder-only 结构

说明 GPT 与 Encoder-only、Encoder-Decoder 模型的区别，重点说明 GPT 是自回归生成模型。

### 2.1.3 GPT 的基本计算流程

GPT 模型的基本流程为：

```text
输入 token 序列
→ Token Embedding
→ Position Embedding
→ 多层 Transformer Block
→ LayerNorm
→ Linear 输出层
→ 预测下一个 token
```

## 2.2 文本表示与输入编码

自然语言文本无法直接输入神经网络，需要先转化为离散 token，再映射为连续向量。本实验中采用字符级 tokenizer 或子词级 tokenizer 完成文本编码。

### 2.2.1 Tokenizer 与 token id

说明 tokenizer 的作用，即将文本切分为 token，并将 token 映射为整数编号。

### 2.2.2 词嵌入 Token Embedding

Token Embedding 用于将离散的 token id 转换为连续向量表示。

### 2.2.3 位置编码 Position Embedding

由于 Transformer 本身不具备顺序感知能力，因此需要加入位置编码表示 token 在序列中的位置信息。

输入向量可以表示为：

```text
输入向量 = Token Embedding + Position Embedding
```

## 2.3 Transformer 核心机制

Transformer 是 GPT 类模型的核心结构。本实验重点实现其中的自注意力、多头注意力、因果遮罩、前馈神经网络、残差连接和层归一化等模块。

### 2.3.1 自注意力机制

自注意力机制用于计算序列中不同 token 之间的相关性。每个 token 会生成 Query、Key 和 Value 向量，通过 Query 与 Key 的相似度计算注意力权重，再对 Value 加权求和，得到上下文相关的表示。

### 2.3.2 多头注意力机制

多头注意力机制将注意力计算分成多个头，每个头可以从不同子空间学习 token 之间的关系。最后将多个注意力头的输出拼接，并经过线性层得到最终结果。

### 2.3.3 因果遮罩机制

GPT 是自回归语言模型，在预测下一个 token 时不能看到未来 token。因果遮罩用于屏蔽当前位置之后的信息，保证模型只能基于历史上下文进行预测。

### 2.3.4 前馈网络、残差连接与层归一化

Transformer Block 中除了注意力层，还包含前馈神经网络。残差连接可以缓解深层网络训练困难问题，层归一化可以稳定训练过程，提高模型收敛效果。

## 2.4 预训练与微调机制

预训练和微调是大语言模型训练流程中的两个重要阶段。

### 2.4.1 预训练任务

预训练是指使用无标签文本数据训练模型，使模型学习通用语言规律。本实验采用 next token prediction 作为预训练任务。

### 2.4.2 微调任务

微调是在预训练模型基础上，使用特定任务数据继续训练，使模型适应具体任务。微调任务可以是文本分类、问答、指令跟随、摘要生成等。

### 2.4.3 预训练与微调的区别

预训练主要学习通用语言规律，微调主要学习特定任务目标。前者通常使用无标签数据，后者通常使用有标签或指令格式数据。

# 3 小型 GPT 模型设计与实现

## 3.1 模型总体设计

本项目实现的小型 GPT 模型采用 Decoder-only Transformer 架构。模型主要由 Token Embedding、Position Embedding、多层 Transformer Block、最终 LayerNorm 和线性输出层组成。

### 3.1.1 模型整体结构

模型结构如下：

```text
输入 token ids
→ Token Embedding
→ Position Embedding
→ Dropout
→ Transformer Block × N
→ Final LayerNorm
→ Linear Head
→ logits
```

### 3.1.2 输入输出形式

模型输入为 token id 序列，形状为：

```text
(batch_size, seq_len)
```

模型输出为每个位置上对词表中所有 token 的预测结果，形状为：

```text
(batch_size, seq_len, vocab_size)
```

## 3.2 核心模块实现

本实验在 `mini_gpt.py` 中实现小型 GPT 的核心模块。

### 3.2.1 Token Embedding 与 Position Embedding

Token Embedding 将 token id 映射为向量，Position Embedding 为序列位置提供位置信息，两者相加后作为 Transformer Block 的输入。

### 3.2.2 Multi-Head Self-Attention

该模块用于计算序列内部 token 之间的依赖关系。实验中使用因果遮罩，保证当前位置无法关注未来位置。

### 3.2.3 Transformer Block

每个 Transformer Block 包含：

1. LayerNorm；
2. Multi-Head Self-Attention；
3. 残差连接；
4. LayerNorm；
5. Feed Forward Network；
6. 残差连接。

### 3.2.4 输出层与损失函数

模型最后通过线性层将隐藏状态映射到词表大小，输出每个位置上对下一个 token 的预测概率分布。训练时使用交叉熵损失函数，比较模型预测结果与真实下一个 token。

## 3.3 模型配置与参数量分析

本实验考虑到普通笔记本或低算力平台运行需求，采用较小规模的模型参数。

### 3.3.1 模型参数配置

| 参数名称           | 含义             | 设置值   |
| -------------- | -------------- | ----- |
| vocab_size     | 词表大小           | 待填写   |

| emb_dim        | 词嵌入维度          | 128   |
| n_heads        | 注意力头数          | 4     |
| n_layers       | Transformer 层数 | 4     |
| dropout        | Dropout 比例     | 0.1   |
| qkv_bias       | QKV 是否使用偏置     | False |
| 参数量            | 模型总参数量         | 待填写   |

### 3.3.2 小参数模型的合理性

与实际大语言模型相比，该模型参数量较小，但保留了 GPT 类模型的核心结构，适合用于课程实验和原理验证。

# 7 问题分析与改进方向

## 7.1 实验中遇到的问题

实验过程中可能遇到的问题包括数据规模较小、模型参数量有限、训练速度较慢、生成文本连贯性不足等。

### 7.1.1 数据方面的问题

小语料规模有限，模型容易过拟合；字符级 tokenizer 表达能力较弱。

### 7.1.2 模型方面的问题

模型参数量较小，无法充分学习复杂语言规律，生成文本质量有限。

### 7.1.3 训练方面的问题

低算力平台训练速度较慢，超参数选择会明显影响训练效果。

## 7.2 模型局限性与改进方向

由于本实验模型参数量较小，训练数据规模有限，因此模型无法达到真实大语言模型的理解和生成能力。本实验重点在于验证 GPT 类模型的基本结构和训练流程。

### 7.2.1 模型局限性

主要包括生成结果不够稳定、上下文建模能力有限、微调任务泛化能力不足等。

### 7.2.2 后续改进方向

后续可以从以下方向改进：

1. 使用更大规模、更高质量的数据集；
2. 使用 BPE tokenizer 替代字符级 tokenizer；
3. 增加模型层数和嵌入维度；
4. 引入学习率调度、梯度裁剪等训练技巧；
5. 尝试指令微调任务；
6. 使用 LoRA 等参数高效微调方法；
7. 构建简单 Web 或命令行交互界面。
